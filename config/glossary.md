# Glossary — German ↔ English

Terms drawn from D1 and D2, the two German documents. Frequencies in brackets
are occurrences across both.

**This file helps the system find and route. It is never quoted back as an
answer.** Authored content stays out of the corpus; only official documents are
indexed.

**Purpose.** Questions arrive in English; two of the four documents are German.
Vector search bridges some of that gap, but BM25 matches literal tokens and
cannot. A student asking about "deadlines" will never keyword-match
`Prüfungsanspruch`. Query expansion adds the German terms before search runs.

---

## Examinations — the core vocabulary

| German | English | Note |
|---|---|---|
| Prüfung | examination | |
| Prüfungsleistung | examination performance | any assessed piece of work |
| Studienleistung | coursework performance | assessed but not an examination |
| Modulprüfung | module examination | may comprise several Modulteilprüfungen |
| Modulteilprüfung [61] | partial module examination | the thing you actually sit; where a module has only one, the two are identical (§ 3 Abs. 1 Satz 3) |
| Masterprüfung [48] | Master's examination | the whole degree assessment, not a single exam |
| Prüfungsart | type of examination | § 12; the list D2 replaced |
| Prüfungsordnung | examination regulations | |
| Prüfungsplan | examination plan | the right-hand half of the study plan table |
| Erfolgskontrolle | assessment / achievement check | used in D2's online-exam sections |

**Modul vs Modulteil is the distinction students trip over.** You retake a failed
*Modulteilprüfung*, not the whole module.

## Documents and legal structure

| German | English | Note |
|---|---|---|
| Studien- und Prüfungsordnung | study and examination regulations | StuPO |
| Allgemeiner Teil | General Part | D1 |
| Besonderer Teil | Special Part | the programme-specific sections |
| Ergänzungssatzung | supplementary statute | D3 |
| Änderungssatzung | amending statute | D2 |
| Satzung | statute | |
| Modulhandbuch | module handbook | D4 — descriptive, **not binding** |
| Landeshochschulgesetz (LHG) | state higher education act | the governing law |
| § / Paragraph | section | **not** "paragraph" |
| Absatz (Abs.) | paragraph | the `(1)`, `(2)` level |
| Satz | sentence | the superscript ¹ ² ³ level |
| Ziffer (Ziff.) / Nummer (Nr.) | number / item | list items |
| Anhang | annex | where D2 put the exam-type definitions |
| Inkrafttreten | entry into force | |
| Bekanntmachung | public announcement | |
| Beurkundung | notarisation | |
| Ausfertigung | official execution | the signed, issued version |

**Citation trap:** `§` translates to *section*, while `Absatz` translates to
*paragraph*. Translating `§` as "paragraph" produces citations that look right
and point to the wrong level.

| German | English | Note |
|---|---|---|
| Master-Thesis | Master's thesis | 30 ECTS, six months for IAI |
| Verteidigung [30] | defence | **not required for IAI** (D3 Re § 3 Para. 1) |
| Mündliche Masterprüfung | oral Master's examination | also not required for IAI |
| Zeugnis | certificate / transcript | English version on request (§ 25 Abs. 6) |
| Urkunde | degree certificate | |
| Mastergrad [5] | Master's degree | M.Sc. for IAI |
| Diploma Supplement | Diploma Supplement | issued in English as standard |
| Einsicht in Prüfungsakten | inspection of examination records | within one year (§ 30) |

`Verteidigung` appears 30 times in D1 and applies to IAI **not at all** — D1
§ 23 is conditional on the Special Part providing for it, and D3 does not. High
frequency is not relevance; a retrieval system weighting on term frequency alone
will over-rank these passages.

## Common phrases in the regulations

| German | English |
|---|---|
| wird wie folgt geändert | is amended as follows |
| wird wie folgt neu eingefügt | is newly inserted as follows |
| gilt entsprechend | applies accordingly |
| Näheres regelt der Besondere Teil | details are governed by the Special Part |
| nicht belegt | not assigned / left blank |
| Entfällt | omitted |
| auf Antrag | on application |
| in der Regel | as a rule |
| unverzüglich | without undue delay |
| ggf. (gegebenenfalls) | where applicable |
| bzw. (beziehungsweise) | or / respectively |

`Näheres regelt der Besondere Teil` is the pointer phrase that sends a reader
from D1 to D3. Any passage containing it is incomplete on its own — a signal the
chunker and the answer prompt should both treat as "follow the reference".
